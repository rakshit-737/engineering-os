# Interview Prep Checklist

## One week before
- [ ] Re-read the JD; map requirements to evidence ([[Resume-Tailoring-Template]])
- [ ] Research the company: product, team, recent engineering blog posts
- [ ] Confirm round types and format (platform, language, duration)
- [ ] Two timed mock coding sessions ([[Interview-DSA-Strategy]])
- [ ] Revise weak patterns from [[Mock-Interview-Log-Template]]
- [ ] Revise CS fundamentals ([[Interview-CS-Fundamentals-Questions]])
- [ ] Prepare 3 STAR stories matched to the company's values ([[Interview-Behavioral-Question-Bank]])
- [ ] Rehearse project defense for every resume project ([[Project-Defense-Guide]])

## Day before
- [ ] Test camera, mic, internet, IDE / shared editor
- [ ] Know the interviewer names if shared
- [ ] Printed or open copy of your resume
- [ ] Two questions to ask the interviewer
- [ ] Sleep

## Day of
- [ ] Join 5 minutes early; water nearby; notifications off
- [ ] Clarify before solving; think aloud
- [ ] Test code by tracing, state complexity
- [ ] Ask your questions at the end

## After
- [ ] Log questions and performance in [[Mock-Interview-Log-Template]]
- [ ] Send thank-you within 24 hours ([[Cold-Email-Templates]])
- [ ] Update the application tracker stage ([[Application-Tracker-Guide]])
