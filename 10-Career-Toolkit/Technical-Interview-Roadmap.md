# Technical Interview Roadmap (12 Weeks)

## Weekly Cadence

- 4 days DSA (2 problems/day)
- 1 day system design basics
- 1 day project deep-dive + resume alignment
- 1 day mock interview + review

## Phase 1 (Weeks 1-4): Foundation

- Arrays, strings, hashmaps, two pointers
- Recursion, binary search, sorting
- SQL basics and joins
- OOP and language fundamentals

## Phase 2 (Weeks 5-8): Intermediate

- Trees, graphs, heaps
- Dynamic programming fundamentals
- API design and backend basics
- Security fundamentals for web apps

## Phase 3 (Weeks 9-12): Interview Simulation

- Timed mixed problem sets
- System design mini-cases
- Behavioral rounds using STAR
- Company-specific prep

## Weekly Review Questions

1. Which patterns still fail under time pressure?
2. Which explanations are unclear?
3. Which resume project needs deeper metrics?
4. Which communication habits need improvement?
