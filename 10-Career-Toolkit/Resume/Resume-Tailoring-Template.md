# Resume Tailoring Template

Tailoring = reordering and rewording **true** content from [[Resume-Engine]] so the reader sees the JD's requirements met in the first 10 seconds. It is never adding skills you do not have.

## Step 1 -- JD keyword mapping

Paste the JD, extract requirements, map each to evidence.

| JD requirement / keyword | Must / nice | My evidence (project, bullet) | Exact wording on resume | Gap? |
|---|---|---|---|---|
| {{e.g. "REST APIs in Java"}} | must | {{project}} | | |
| | | | | |

Rules:
- Use the JD's exact term where it is truthful (e.g. "Spring Boot", not "Java web framework") -- keyword screens are literal.
- A "must" with no evidence is a gap: build a small proof (1-2 weeks) or accept lower odds. Do not paper over it.
- If more than about three musts are unmet, deprioritize the application.

## Step 2 -- Choose a variant

| Variant | Lead section | Top 3 projects | Skills order |
|---|---|---|---|
| SWE / backend | Projects / experience | | languages, frameworks, databases, cloud |
| Security (SOC / AppSec / cloud sec) | Projects + labs / CTF | | security tooling, languages, cloud |
| AI / ML | Projects + research | | ML frameworks, languages, data |
| Research | Research experience / publications | | methods, frameworks |

## Step 3 -- Edit

- Reorder bullets so the most JD-relevant one is first in each entry.
- Cut anything that does not support this role.
- Keep 1 page (student / new grad).
- Save as `Resume_{{Name}}_{{Role}}_{{Company}}.pdf`; record the variant in the tracker ([[Application-Tracker-Guide]]).
