# Resume Review Checklist

## Honesty
- [ ] Every number is measured or sourced, and I can explain how it was measured
- [ ] Every listed skill is used in at least one project or role on the page
- [ ] Titles, dates and org names match offer letters / certificates exactly
- [ ] I can defend every bullet for 5 minutes ([[Project-Defense-Guide]])

## Content
- [ ] Top third of the page shows the JD's top requirements
- [ ] Each bullet follows action + what + how + result ([[Resume-Engine]])
- [ ] No bullet starts with "Responsible for", "Worked on" or "Helped"
- [ ] 2-4 projects, most relevant first, each with a working link (repo / demo / write-up)
- [ ] No filler (objective statements, "hardworking", "references on request")

## Format
- [ ] One page (student / new grad)
- [ ] Single column, standard headings (Education, Experience, Projects, Skills)
- [ ] PDF text is selectable; pasting into a plain editor reads in the right order
- [ ] Consistent date format, tense and punctuation
- [ ] Readable font size and margins
- [ ] File name includes name and role

## Links and contact
- [ ] Email, phone, GitHub, LinkedIn correct and clickable
- [ ] GitHub pinned repos match resume projects and have READMEs
- [ ] No private data you would not want forwarded

## Final
- [ ] Spell-checked and read aloud once
- [ ] Reviewed by one other person
- [ ] Variant name logged in the application tracker
