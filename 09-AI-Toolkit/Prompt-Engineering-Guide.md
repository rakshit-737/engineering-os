# Prompt Engineering Guide

## Core Framework

Use this structure:

1. Role
2. Objective
3. Context
4. Constraints
5. Output format
6. Quality checks

## Reliability Additions

- Ask for assumptions
- Ask for edge cases and failure modes
- Ask for test plan
- Ask for reusable artifact output

## Prompt Iteration Loop

- Baseline prompt
- Analyze failures
- Add constraints/examples
- Re-run and compare
- Version the prompt
