# Publication Checklist

## Pre-Submission

- [ ] Clear novelty statement
- [ ] Strong baseline comparison
- [ ] Error analysis included
- [ ] Limitations section included
- [ ] Reproducibility details included

## Writing

- [ ] Abstract includes problem-method-result
- [ ] Figures readable and captioned
- [ ] Table units and metrics defined
- [ ] References complete and consistent

## Submission Package

- [ ] PDF camera-ready format
- [ ] Supplementary material prepared
- [ ] Source code clean and tagged
- [ ] License and data permissions verified

## Post-Submission

- [ ] Reviewer-response draft prepared
- [ ] Improvement backlog created
- [ ] Replication script archived
