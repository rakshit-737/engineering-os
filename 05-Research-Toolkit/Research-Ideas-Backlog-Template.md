# Research Ideas Backlog Template

Capture every idea quickly and commit to very few. Review the backlog monthly. An idea moves to active only after a quick literature check and a scored triage.

## Capture (append, 2 minutes each)

| ID | Date | Idea (one sentence) | Source (paper, class, bug, conversation) | Status |
|---|---|---|---|---|
| I-01 | | | | new |

Status values: `new` → `checked` → `active` / `parked` / `dropped`.

## Triage (score 1-3 each)

| ID | Impact (who cares if it works?) | Feasibility (data, compute, skills available?) | Novelty (quick search found nothing close?) | Fit (advisor, course, career goal) | Time to first signal (3 = under 2 weeks) | Total |
|---|---|---|---|---|---|---|
| | | | | | | |

Rules:
- Novelty scored after at least a 30-minute search (see Check 4 in [[Novelty-Checklist]]).
- Feasibility of 1 means drop or park, regardless of total.
- At most 1-2 active ideas at a time.

## Promotion Checklist (new → active)

- [ ] 3 closest papers found and noted ([[Paper-Note-Template]])
- [ ] Gap written in one sentence
- [ ] Hypothesis drafted with [[Hypothesis-Template]]
- [ ] Smallest experiment that could kill it identified
- [ ] Advisor or peer consulted
