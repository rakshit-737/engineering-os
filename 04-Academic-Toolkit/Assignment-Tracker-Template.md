# Assignment Tracker Template

One tracker for all courses. Each assignment also gets its own write-up from [[Assignment-Template]].

## Status Pipeline

`assigned` → `decomposed` (within 24 h) → `implementing` → `writing` → `reviewed` → `submitted` → `graded`

Red flags reviewed every Sunday:
- Anything still `assigned` after 3 days
- Anything due within 3 days that isn't at `writing` yet

## Priority Rule

Priority = weight % ÷ days to deadline. Work the highest number first. Low weight with a far deadline can be batched on Saturdays.

## Per-Assignment Checklist

Copy under each assignment when it arrives:

- [ ] Decomposed into requirements (15 min) using [[Assignment-Template]]
- [ ] Unclear requirements asked about within 48 h
- [ ] Effort budget set
- [ ] Implementation done
- [ ] Write-up done the same day as implementation
- [ ] Checked against every requirement
- [ ] Submitted, with confirmation saved
- [ ] Feedback read and one lesson noted
