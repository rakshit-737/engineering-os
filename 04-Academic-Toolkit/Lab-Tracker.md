## Per-Experiment Checklist

- [ ] Read the manual and wrote aim, theory and predicted result before the session
- [ ] Brought required materials (record, manual, code on USB or repo)
- [ ] Raw observations recorded during the session
- [ ] Record completed the same evening
- [ ] Record signed or submitted by the deadline
- [ ] Three likely viva questions answered in one line each

## End-Lab Exam Prep

- [ ] List of all experiments with a one-line procedure each
- [ ] Code or circuits for each experiment reproduced once from memory
- [ ] Common viva questions per experiment collected from seniors or TAs
- [ ] Timed practice run of the two hardest experiments
