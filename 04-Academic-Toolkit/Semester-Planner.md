# Semester Planner

Fill in week 1 of semester (60 min). Update trackers weekly during the Sunday review — a stale planner is worse than none, it lies to you.

## Semester Goals — 3 only

1. GPA target: (per-course grade targets in the tracker below — GPA is an output, courses are the inputs)
2. Skill target: (one, with artifact: "ship X", not "learn X")
3. Career target: (applications count / internship secured / N interviews)

## Weekly Rhythm

| Day | Slot | Default use |
|-----|------|-------------|
| Mon-Fri | Block 1 (90 min, before classes if possible) | Hardest current course |
| Mon-Fri | Block 2 (90 min) | Build/skill target (Engineering OS daily loop) |
| Sat | Morning | Weekly problem-solving under time (interview prep) |
| Sat | Afternoon | Assignments/labs due next week |
| Sun | 60 min | Weekly review ([[Weekly-Review]]) + plan week |

Protect Block 1 hardest. A rhythm that survives a bad week beats an ambitious one that doesn't.

## Assignment Tracker

Priority = days-to-deadline vs weight. High weight + close deadline first; low weight + far = batch on Saturdays.

| Course | Assignment | Deadline | Weight % | Status (not started/decomposed/implementing/writing/done) | Next action |
|--------|-----------|----------|---------:|--------|-------------|
| | | | | | |

Rule: decompose (15 min, using [[Assignment-Template]]; track all of them in [[Assignment-Tracker-Template]]) the day it's assigned. "Not started" older than 3 days = red flag in Sunday review.

## Exam Preparation

Start T-21 days per course. Sequence: syllabus map → PYQs (past-year questions are the highest-signal study material that exists) → weak-topic drills → mocks under time.

| Course | Syllabus mapped | PYQs done (target: 5 yrs) | Mocks under time | Weak topics (from mock errors, not feelings) |
|--------|----------------|---------------------------:|-----------------:|----------------------------------------------|
| | | | | |

## SGPA/CGPA Math

Tracked in `CGPA-Tracker.csv`; full method and worked example in [[Grade-Calculation-Guide]] (or use the calculator in the web app at `/academic`). SGPA = Σ(credits × grade-point) / Σ(credits). Before finals, compute per course: minimum final-exam score needed for target grade — tells you where marginal study hours actually pay.
