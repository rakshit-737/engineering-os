# Code of Conduct

Be respectful, assume good intent, and keep discussion technical. Harassment, discrimination and personal attacks are not tolerated. Security content must be used only for authorized, legal purposes.

Report conduct concerns privately to the maintainer via GitHub (@rakshit-737). This project follows the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
