# Engineering OS

A permanent, reusable engineering ecosystem for CS + Cybersecurity + AI work.

## Purpose
This repository is designed as your personal operating system for learning, building, researching, interviewing, and shipping. It is optimized for:

- Reuse over one-off answers
- Automation over manual repetition
- Documentation over memory
- Systems over motivation

## Structure

- `00-Command-Center` - Mission dashboard, weekly reviews, and execution plan
- `01-Obsidian-Vault` - Linked knowledge base for core CS, cybersecurity, AI/ML, and research
- `02-Prompt-Library` - Reusable prompt packs for coding, research, interviews, writing, and review
- `03-Coding-Library` - Reusable implementations with notes and complexity references
- `04-Academic-Toolkit` - Assignment, lab, project, and semester planning templates
- `05-Research-Toolkit` - Literature review, experiment logs, novelty checks, publication pipeline
- `06-Cybersecurity-Toolkit` - Cheat sheets, methodology, and practical checklists
- `07-Developer-Toolkit` - README, PR, issue, API doc, architecture, and debugging templates
- `08-Automation-Toolkit` - Python + PowerShell scripts and CI workflow templates
- `09-AI-Toolkit` - Prompt engineering, RAG, evaluation, and deployment playbooks
- `10-Career-Toolkit` - Resume, outreach, application tracker, interview system
- `11-Project-Templates` - Copy-paste project starters: FastAPI service, Docker worker, secure coding examples

## Daily Usage Loop (15-30 min)

1. Open `00-Command-Center/Daily-Dashboard.md`
2. Pick one `Build`, one `Learn`, and one `Career` task
3. Timebox each for 45 to 90 minutes
4. Log outputs into the relevant toolkit
5. End with one artifact committed to git

## Weekly Usage Loop (60 min)

1. Review `00-Command-Center/Weekly-Review.md`
2. Promote useful notes into templates or scripts
3. Archive stale material
4. Define top 3 outcomes for next week

## Long-Term Rules

- Every repeated action gets a checklist or script
- Every solved bug gets a troubleshooting note
- Every project gets docs, tests, and a postmortem
- Every study cycle ends with a summary + flashcards + quiz
- Every research reading gets a structured paper summary

## Suggested Git Strategy

- Branches: `feat/*`, `fix/*`, `docs/*`, `research/*`
- Commit style: `type(scope): summary`
- Weekly tag: `week-YYYY-MM-DD`
