# Achievement Log Template

Log achievements when they happen, with a link to the evidence. At résumé time you'll have specifics instead of vague memories.

Log it if it's **measurable, verifiable, or someone else valued it**: a shipped project, a result with a number, a contest rank, a merged PR, a grade, positive feedback, a problem you solved that others couldn't.

## Entry Template

### YYYY-MM-DD: <title>

- Category: project / academic / research / competition / open source / leadership / other
- Situation (1 line):
- What I did (my part only, with the technical specifics):
- Result (a number if one exists; otherwise the concrete outcome):
- Evidence link (repo, PR, certificate, report, message):
- Skills demonstrated:
- Draft résumé bullet (action verb + what + measurable result):

- [ ] Evidence link works and is public or shareable
- [ ] Converted into a STAR story if it's interview-worthy

## Bullet Formula

`<Verb> <what you built or changed> using <tech>, resulting in <measured result or concrete outcome>.`

Only use numbers you can defend in an interview. If there is no number, state the concrete outcome ("adopted by 3 lab groups") rather than inventing a percentage.
