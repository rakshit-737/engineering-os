## Practice Loop (per concept)

1. Read the note → answer its interview questions aloud
2. Implement the core idea from memory (no peeking)
3. Run the relevant tests against your implementation
4. Solve 2 problems that use it ([[Interview-Prep-Index]] has the patterns)
5. Write a one-line summary — if you can't compress it, you don't own it yet
