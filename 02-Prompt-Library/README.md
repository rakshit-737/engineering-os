# Prompt Library

Use these prompts as reusable operating procedures, not one-time requests.

## How to Use

1. Copy a prompt template
2. Fill variables in `{braces}`
3. Save run output in your vault or project docs
4. Refine and version prompts over time

## Categories

- Coding and architecture
- Debugging and testing
- Research and paper analysis
- Cybersecurity and threat modeling
- Interview and career
- Documentation and teaching

## Prompt Design Rules

- Include context, constraints, desired output format, and quality criteria
- Request checklists, edge cases, and reusable artifacts
- Require explicit assumptions and validation steps
